# ConectaDoa

Projeto da ONG ConectaDoa criado com Vite+.

## Como rodar o projeto

1. Instale as dependências:
   vp install

2. Em um terminal, rode a API:
   vp run api

3. Em outro terminal, rode o frontend:
   vp dev

4. Abra http://localhost:5173 no navegador.
   A página deve mostrar "Status da API: ok".
